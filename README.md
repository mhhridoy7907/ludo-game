# Ludo Game (HTML + CSS + JavaScript)

A fully functional Ludo board game built using only Vanilla HTML, CSS, and JavaScript.
This project includes complete game logic, animations, bots, and interactive UI.

## Features
- Real-time dice rolling system
- 2–4 player support
- Bot & Random AI players
- Smart move validation system
- Token killing (capture system)
- Win detection (4 tokens home)
- Clean Ludo board UI design
- Responsive layout (desktop & mobile friendly)

## Technologies Used
- HTML5
- CSS3 (Grid + Flexbox)
- Vanilla JavaScript (ES6 Classes)
- Canvas API (for animation rendering)


## How to Play
- Open index.html in your browser
- Enter player names and select colors
- Click Start Game
- Roll the dice 🎲
- Select token to move
- First player to bring all 4 tokens home wins 🏆

## Game Logic
- Each player has 4 tokens
- Dice value controls movement
- Rolling 6 gives extra chance
- Tokens can kill opponent tokens on same position
- Safe zones prevent capture
- Game ends when a player reaches 4/4 tokens home
